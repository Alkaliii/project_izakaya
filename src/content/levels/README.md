Tips,

Add new levels to the src/levels folder
You can duplicate the "empty.tscn" to ensure it has critical elements
Press F6 while the level is open to test it (or the film clapper button)
The sky and the level are both tile maps that you can edit
	Note: Due to how the background works, please build the level above the red line x axis line
	Note: The sky only has to fill the purple box highlighted by the camera, the parallax node will repeat it (on the x axis only, draw the sky at the y level you want it at)
	Note: I need to write an enemy spawner, so if you place any down I'll probably replace them later
	Note: Some tiles like signs or the fence gate will get replaced by bespoke objects
	Note: Opening the fairy and player scenes might cause the engine to hang because of my stupid shader

Let me know if you need anything specific or have a question about editing a this.
